# Moodle Administration Troubleshooting Case Study

**Portfolio Case Study | Damaris – Digital Learning Specialist**

## 1. Case Study Overview

This case study demonstrates a structured approach to investigating Moodle quiz access and navigation issues, with a focus on learner attempts, quiz configuration and lecturer support.

The scenario is based on a Moodle support situation in which a learner accessing a quiz containing five questions was taken directly to Question 5 instead of being able to attempt the questions in the expected sequence.

The case illustrates the importance of investigating quiz configuration and attempt status before recommending changes.

## 2. Problem Description

A learner reported that, when opening a Moodle quiz containing five questions, the quiz interface directed them to Question 5 rather than allowing them to work through the questions in the expected order.

The attempt status indicated that the learner was resuming an existing attempt.

This raised the need to investigate whether the behaviour was related to the existing attempt, quiz navigation settings or the configuration of the quiz itself.

## 3. Investigation Approach

A structured troubleshooting approach was considered.

### 3.1 Review quiz navigation settings

The quiz configuration should be reviewed to establish whether question navigation is sequential or free navigation.

Sequential navigation restricts learners from moving freely between questions and requires them to follow the configured question sequence.

### 3.2 Review the learner's attempt status

The existing attempt should be examined to establish:

- Whether the learner had previously started the quiz.
- Whether the attempt was saved or still in progress.
- Whether the learner was resuming an earlier attempt.
- Whether the current question position was retained from the previous session.

### 3.3 Review attempt management

The lecturer should review the learner's existing attempt before considering any intervention.

This is important because deleting, resetting or changing an attempt without appropriate checks could affect the learner's submitted work.

## 4. Recommended Resolution Approach

The appropriate response is to:

1. Confirm the learner's quiz attempt status.
2. Review the quiz navigation configuration.
3. Establish whether the learner is resuming a previously saved attempt.
4. Ask the lecturer to review the attempt and determine the appropriate action.
5. Preserve any valid learner responses.
6. Provide the learner with guidance based on the lecturer's decision.
7. Test the relevant configuration where appropriate.

Any attempt reset or deletion should only be undertaken by an authorised lecturer or administrator after considering institutional assessment policies.

## 5. Professional Considerations

The scenario highlights several important Moodle administration principles:

- Understanding quiz navigation behaviour.
- Interpreting saved and in-progress quiz attempts.
- Investigating configuration-related issues.
- Protecting learner assessment records.
- Distinguishing lecturer responsibilities from LMS administrator responsibilities.
- Communicating technical findings clearly.
- Avoiding unnecessary changes to active assessments.

## 7. Professional Learning

Effective Moodle administration requires more than changing settings. It involves understanding how configuration choices affect the learner experience, examining available evidence and recommending appropriate action.

A structured troubleshooting process helps prevent unnecessary disruption to assessments while supporting lecturers and learners.
